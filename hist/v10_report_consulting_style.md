# Version 10: 보고서 컨설팅 스타일 개선

## 날짜
2026-01-03

## 작업 내용

### 1. 상세 정보 스타일 수정
- `.details` 배경색을 `#f8fafc` (밝은 회색)으로 변경
- 텍스트 색상 `#334155` (진한 회색)으로 가독성 확보
- 테두리 추가로 영역 구분 명확화

### 2. Executive Summary (종합 요약) 추가
- 진단 대상, 총 점검 항목 수, 취약점 발견 수
- 종합 위험도 게이지 (안전/주의/경고/심각)
- Critical, High 취약점 별도 강조

### 3. 예상 피해 (Impact) 설명 추가
- 각 취약점별 예상 피해 자동 표시
- SQL Injection, XSS, RCE 등 주요 취약점별 비즈니스 영향 설명
- 개인정보보호법 과태료 등 법적 리스크 명시

### 4. 예상 비용 명세서 추가
- 심각(Critical) 취약점: 5,000,000원/건
- 높음(High) 취약점: 3,000,000원/건
- 중간(Medium) 취약점: 1,500,000원/건
- 낮음(Low) 취약점: 500,000원/건
- 보안 컨설팅 기본: 2,000,000원
- 모의해킹 (Critical 발견 시): 8,000,000원

### 5. 세부 지표 표시
- 인프라/웹 스크립트 개수 표시
- 실행된 스크립트 vs 스킵된 스크립트
- 성능 향상률 (%) 계산 및 표시
- 모듈별 (web, db, os 등) 스크립트 현황
